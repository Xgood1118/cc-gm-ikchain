# 两骨 IK 求解

一个能在关节限制下解两骨 IK、并在无解时给出最大可达位置的求解器。纯 Python 标准库实现，无第三方依赖。

## 保留签名

- `Vec2`：二维向量（dataclass，字段 `x` / `y`）
- `solve_two_bone(base, target, l1, l2, bend=1.0, limit=None)`
- `joint_limit(angle, lo, hi)`
- `reach(l1, l2)`

位置参数与原骨架完全一致；`bend`（肘朝向，>=0 逆时针，<0 镜像）与
`limit=(lo, hi)`（中间关节内角限制，弧度）为追加的可选关键字参数，老调用方式不受影响。

## 角度约定

| 角 | 含义 | 范围 |
|---|---|---|
| `angles["base"]` (θ1) | 第一根骨相对 +x 轴的绝对方向 | (-π, π] |
| `angles["joint"]` (β) | 中间关节内角，π=完全伸直，0=完全折叠 | [0, π] |
| `angles["bone2"]` (θ2) | 第二根骨的绝对方向 | (-π, π] |

## 返回状态 `status`

| status | 含义 | `ok` |
|---|---|---|
| `ok` | 解析解精确到达目标，误差 ≤ 1e-9，约束全部满足 | True |
| `max_reach` | 目标超出最大可达距离，朝目标方向完全伸展，骨长不变 | False |
| `min_reach` | 目标落入最小半径 `|l1-l2|` 内侧，完全折叠 | 视误差而定 |
| `limited` | 无约束关节角越过限制，已退化到限制边界，末端为限制下最近可达位置 | False |
| `no_solution` | 限制区间非法 / 与 [0,π] 无交集 / 负骨长；不返回任何位姿（`end`、`elbow` 为 `null`） | False |

只要返回了位姿，关节角一定在限制区间内，绝不返回越界解。求解为纯解析计算，两次结果完全一致。

## data/targets.json 实跑结果

基座均为 `(0, 0)`，骨长 l1=3、l2=4，最大可达距离 `reach = 7`。

| # | 目标 | status | 末端误差 | 关节角 β (rad) | 关节角 β (deg) | 最大伸展位置 |
|---|---|---|---|---|---|---|
| 0 | (3, 4)，距离 5 | `ok` | 6.280e-16（JSON 中记为 0.0） | 1.570796326795 | 90.0000° | (4.2, 5.6) |
| 1 | (30, 40)，距离 50 | `max_reach` | 43.000000 | 3.141592653590 | 180.0000° | (4.2, 5.6) |

### 目标 0：(3, 4) — 可达，精确命中

- 末端 `end = (3, 4)`，误差 6.28e-16（浮点噪声）。
- 肘 `elbow = (3, 0)`，θ1 = θ2 = 0.5π（90°），关节内角 β = 0.5π（90°）。
- 反算骨长：基座→肘 = 3，肘→末端 = 4，骨长不变。
- 参考最大伸展位置（朝目标方向伸直 7 个单位）：`(4.2, 5.6)`。

### 目标 1：(30, 40) — 超范围，最大伸展

- 目标距离 50 > 最大可达 7，`status=max_reach`，骨没有被拉长（反算仍为 3、4）。
- 沿目标方向（角度 0.927295 rad ≈ 53.13°）完全伸直：
  肘 `elbow = (1.8, 2.4)`，末端 `end = (4.2, 5.6)`，即 `max_extend_position`。
- 关节内角 β = π（180°），残余误差 = 50 − 7 = **43.0**。

完整字段（含 `reason` 说明、各角度、`max_reach` 等）见生成的 `solution.json`。
